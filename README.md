# E-Commerce Checkout Test Automation

## Business Context
Automated testing for Lagos e-commerce platform processing 10,000+ 
daily transactions through Paystack gateway.

## Problem Solved
- Eliminated 8 hrs/week manual testing
- Catches payment bugs before production
- Ensures consistent checkout experience

## Tech Stack
- Playwright (JavaScript)
- Page Object Model
- GitHub Actions CI/CD

## Test Coverage
✅ Happy path checkout
✅ Cart management
✅ Payment processing
✅ Form validation
✅ Error handling

## Running Tests
```bash
npm install
npx playwright test
npx playwright show-report
```
